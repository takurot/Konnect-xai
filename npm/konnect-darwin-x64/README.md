# @konnect-xai/konnect-darwin-x64

Native Konnect MCP server for macOS Intel. The
[`@konnect-xai/konnect`](https://www.npmjs.com/package/@konnect-xai/konnect)
launcher installs this package automatically on the matching platform. Enable
optional dependencies when installing the launcher.

See the [Konnect-xai repository](https://github.com/takurot/Konnect-xai) for
KiCad and MCP client setup.
